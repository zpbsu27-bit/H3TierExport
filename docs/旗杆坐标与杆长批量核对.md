# 1999 原版旗杆坐标与帧几何核对

`flag-pole-audit` 使用内置的 1999 Complete `H3sprite.lod` 原始 DEF 帧头和 palette index 5 像素，不使用 HD 版旗帧测量杆尖。数据库固定原始 LOD SHA-256 `57caf2c50573f33a0d91e4222e51d3a73c136d44decf59dde21cacad88fe5d66`，每个 DEF 另带自己的 SHA。内置表包含 2,565 个 DEF、34,324 个逻辑帧，其中 49 个 `AVM` 身份共 474 帧。12 个非矿物帧的原始帧头不符合画布几何，保留原值并标记 `UNRESOLVED_INVALID_FRAME_HEADER`，不能自动注册。

## 三类坐标必须区分

- **画布 / 裁片 / 裁片原点**：直接来自 1999 DEF 当前组、当前帧的帧头；裁片原点是裁片左上角在完整画布中的坐标。
- **旗面框**：从同一原版帧的调色板 5 号像素识别。框为 `[左, 上, 右, 下]`，右和下是开区间。软件依据原旗面形状标出可能的挂接侧可见像素；这不是已经证明的建筑杆顶，也不能由旗面的尺寸推出建筑杆长。
- **图片注册偏移**：导入图片的完整原版画布左上角在该图片内的位置。它是图片的变换参数，不是 DEF 的裁片原点。完整原版画布的整数倍自动推定为 `(0,0)`；只含原版裁片的整数倍自动推定为 `-裁片原点×倍率`。尺寸相同不证明画面实际注册正确，测量前都须人工确认；其他高清母版还须手工设置比例和偏移。

例如 `AVMSAWR0` 的 `0_0` 画布为 `160×96`，裁片 `160×74`，裁片原点 `(0,22)`；原版旗面可见框为 `[92,78,106,83]`，挂接侧的可见像素参考是 `(105,78)`。当导入完整 3X 画布 `480×288` 时注册偏移是 `(0,0)`；当导入仅裁片的 `480×222` 时注册偏移是 `(0,-66)`。不同矿按各自原版数据核对，不能共用一套旗位。

完整旗面按 1999 DEF 中真实 41 或 42 个旗色像素识别。被遮挡的不完整旗面不强行补成确定位置：例如 `AVMSWSN0` 只观测到 34 个旗色像素，实际可见框为 `[110,5,123,10]`，两种可能的完整旗框均作为候选保留，不输出精确旗杆位移。没有匹配旗面图案的对象仍能查询原版画布、裁片与原点；不能由此推断游戏没有占领旗。

## 查询和审图

图形界面可以直接选择 `AVMSAWR0/0_0.png`、`AVMGESW0/0_15.png` 等原生帧名：软件从父文件夹识别 DEF、从文件名识别组和帧；也支持身份命名的单张 PNG 和批量清单。使用 `dist/H3TierExport.exe` 的命令行：

```powershell
# 查看一个身份全部 group 0 原生帧（只读）
.\H3TierExport.exe flag-pole-audit --catalog AVMGESW0

# 查看某个原生帧
.\H3TierExport.exe flag-pole-audit --catalog AVMSAWR0 --group 0 --frame 0

# 以完整原版画布或裁片的整数倍导入 3X，软件自动识别注册
.\H3TierExport.exe flag-pole-audit `
  --image "AVMSAWR0=D:\path\AVMSAWR0\0_0.png" --group 0 --frame 0 `
  --outdir "D:\path\new-audit-directory"
```

界面用蓝框显示原版裁片、黄框显示完整旗面、绿点显示形状推断的挂接侧可见像素，橙框显示残缺旗面。先核对并勾选“已确认注册”，再标记画中杆头、杆脚并导出布局 JSON；手工标记的是画面地标，不能由 Alpha 或框线自动证明。杆长可以由同组人工标注的中位数或明确目标给出，不存在全矿通用的官方杆长。

批量清单沿 `h3.flag-pole-audit-manifest.v1`，每项写原版 `identity`、`group`、`frame`、输入 `image_path`/`image_sha256`、`pixels_per_1x` 和 `native_origin_px`；同一 DEF 的不同帧可以同时列入。`reference_database_sha256` 必须是实际内置 gzip 数据库的 SHA。未按完整画布或裁片自动注册的自定义输入，网页需勾选“已确认注册”后才能得到标注差值。再用 `--verify-layout` 和清单/布局 SHA 生成诊断报告。旧数据库冻结的清单绑定旧 SHA，不能冒充新库结果。

## 重建数据库

在本机已核实原版 LOD 后，以新的输出文件重建；命令不会改游戏资源：

```powershell
.\venv-win\Scripts\python.exe -B scripts\build_1999_native_flag_catalog.py `
  --archive "{VX-root}\HoMM 3 Complete\Data\H3sprite.lod" `
  --archive-sha256 57caf2c50573f33a0d91e4222e51d3a73c136d44decf59dde21cacad88fe5d66 `
  --out "D:\path\new-flag-pole-reference-1999.json.gz"
```

工具输出是审图与来源证据，不自动修母版、导出 3X、更新 MOD 或证明实际游戏已通过。旧 `spriteFlagsInfo` 和 HD 旗帧资料仅属于其他历史/专项工作流，不能作为本审计的 1999 几何依据。
